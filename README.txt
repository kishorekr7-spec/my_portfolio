KISHORE KUMAR B. — PORTFOLIO

HOW TO RUN
1. Extract the ZIP folder.
2. Open the kishore_portfolio folder in Visual Studio Code.
3. Keep the assets folder beside index.html, style.css and script.js.
4. Double-click index.html to preview in your browser.
5. For editing, update index.html and style.css, then refresh the browser.

FILES
- index.html: portfolio content and structure
- style.css: responsive design and styling
- script.js: mobile navigation and footer year
- assets/profile.jpg: uploaded profile photo
- assets/Kishore-Kumar-Resume.pdf: uploaded resume
